ПАПКА ДЛЯ ВИДЕОФАЙЛА

Сейчас видео подключено через YouTube, поэтому эта папка может оставаться пустой.

Чтобы использовать файл вместо YouTube:
1. Положите сюда файл pitch.mp4
2. Откройте index.html в текстовом редакторе (Блокнот, VS Code)
3. Найдите строку  video: {  и впишите  src: "video/pitch.mp4",  а embed очистите (embed: "")
4. Сохраните файл и обновите страницу.

Подробности в README.md в корне папки.
